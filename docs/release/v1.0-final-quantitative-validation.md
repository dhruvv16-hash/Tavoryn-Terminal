## 2. DCF Intrinsic Valuation Model

### 2.1 Core Mathematical Formulations
The valuation engine (`lib/fn/dcf.js`, `public/js/fn/dcf.js`) implements discounted cash flow valuation:

1. **Explicit 5-Year Forecast Discounting:**
   $$EV_{\text{explicit}} = \sum_{t=1}^{5} \frac{FCFF_t}{(1 + WACC)^t} \quad \text{where } FCFF_t = FCFF_0 \times (1 + g)^t$$
2. **Terminal Value (Gordon Growth Perpetuity):**
   $$TV = \frac{FCFF_5 \times (1 + g_{\text{term}})}{WACC - g_{\text{term}}} \quad \text{where } WACC > g_{\text{term}}$$
   $$PV(TV) = \frac{TV}{(1 + WACC)^5}$$
3. **Enterprise Value:**
   $$EV = EV_{\text{explicit}} + PV(TV)$$
4. **Enterprise-to-Equity Value Bridge:**
   $$\text{Equity Value} = EV - \text{Net Debt} = EV + \text{Cash \& Equivalents} - \text{Total Debt}$$
5. **Intrinsic Value Per Diluted Share:**
   $$\text{Intrinsic Value Per Share} = \frac{\text{Equity Value}}{\text{Diluted Shares Outstanding}}$$
6. **Margin of Safety:**
   $$\text{Margin of Safety (\%)} = \frac{\text{Intrinsic Value} - \text{Market Price}}{\text{Market Price}} \times 100\%$$

### 2.2 Independent Numerical Benchmark Reconciliation
- **Parameters:** $FCFF_0 = \$100.00\text{M}$, $g = 10\%$, $WACC = 10\%$, $g_{\text{term}} = 3\%$, Cash = $\$50\text{M}$, Debt = $\$150\text{M}$, Shares = $50\text{M}$, Price = $\$40.00$.
- **Hand Calculation Results:**
  - $PV(\text{Explicit FCF}) = 5 \times \$100.00\text{M} = \$500.00\text{M}$
  - $FCFF_5 = \$100 \times 1.10^5 = \$161.051\text{M}$
  - $TV = \frac{\$161.051\text{M} \times 1.03}{0.10 - 0.03} = \frac{\$165.88253\text{M}}{0.07} = \$2,369.7504\text{M}$
  - $PV(TV) = \frac{\$2,369.7504\text{M}}{1.10^5} = \$1,471.4286\text{M}$
  - $EV = \$500.00\text{M} + \$1,471.4286\text{M} = \$1,971.4286\text{M}$
  - $\text{Equity Value} = \$1,971.4286\text{M} - (\$150\text{M} - \$50\text{M}) = \$1,871.4286\text{M}$
  - $\text{Intrinsic Value Per Share} = \frac{\$1,871.4286\text{M}}{50\text{M}} = \$37.4286$
  - $\text{Margin of Safety} = \frac{\$37.4286 - \$40.00}{\$40.00} = -6.4286\%$
- **Engine Output:** Exact match across all fields (`test/dcf.test.js` Test 1, error $< 10^{-4}$).

### 2.3 Metamorphic Properties Verification
Verified in `test/dcf.test.js` Test 13:
1. $\frac{\partial EV}{\partial g} > 0$: Higher growth rate strictly increases Enterprise Value.
2. $\frac{\partial EV}{\partial WACC} < 0$: Higher cost of capital strictly reduces Enterprise Value.
3. $\Delta \text{Cash} = \Delta \text{Equity Value}$ with $\Delta EV = 0$: Additional cash flows directly into equity value.
4. $\Delta \text{Debt} = -\Delta \text{Equity Value}$ with $\Delta EV = 0$: Additional debt reduces equity value 1:1.
5. Linear share dilution: Doubling shares halves per-share intrinsic value with invariant EV and Equity Value.
6. Market price independence: Market price shifts alter Margin of Safety while intrinsic value remains invariant.

## 3. Portfolio Stress Testing Engine

### 3.1 Crisis Scenarios Inventory
The stress testing engine (`lib/fn/stress.js`, `public/js/fn/stress.js`) models multi-asset portfolio vulnerability across 8 historical crisis scenarios and 4 macroeconomic shocks:
1. **2008 Global Financial Crisis:** Equities $-52.6\%$, Commodities $-40.0\%$, Treasuries $+15.0\%$.
2. **2020 COVID-19 Flash Crash:** Equities $-33.9\%$, Commodities $-35.0\%$, Treasuries $+8.0\%$.
3. **2022 Fed Rates Shock:** Equities $-24.9\%$, Commodities $+20.0\%$, Treasuries $-15.0\%$.
4. **2000 Dot-Com Tech Wreck:** Tech Equities $-82.0\%$, Broad Market $-49.1\%$.
5. **1987 Black Monday:** Equities $-22.6\%$.
6. **2011 US Debt Downgrade:** Equities $-17.5\%$, Gold $+12.0\%$.
7. **2015 China Currency Devaluation:** Equities $-12.4\%$, Emerging Markets $-20.0\%$.
8. **2023 SVB Regional Banking Crisis:** Financials $-35.0\%$, Broad Market $-14.2\%$.

### 3.2 Asset Class Shocks & Reconciliation
- **Long Positions:** $\Delta V_i = V_i \times \beta_i \times \text{Shock}$.
- **Short Positions:** $\Delta V_i = -V_i \times \beta_i \times \text{Shock}$ (gain value during market downturns).
- **Cash Preservation:** Cash assets maintain 100% principal value across all market shocks.
- **Reconciliation Identity:** $\text{Stressed Portfolio Value} = \text{Initial Portfolio Value} + \sum \Delta V_i$.

## 4. Algorithmic Replay & Backtest Engine

The historical backtesting engine (`lib/replay-engine.js`, `public/js/fn/btst.js`) operates under verified quantitative safeguards:
1. **Zero Lookahead Bias:** Decisions at bar $t$ Close execute on bar $t+1$ Open. Verified via future-bar perturbation testing.
2. **Slippage & Commission Modeling:** Enforces realistic trading costs and bid/ask spreads.
3. **Stop-Loss Gap Execution:** If bar $t+1$ opens below a long stop loss, the fill is executed at the Open price with slippage, not at the idealized stop price.
4. **Reproducibility:** Two consecutive runs with identical parameters produce byte-identical trade logs and equity curves.
