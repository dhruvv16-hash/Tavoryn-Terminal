## 2. Discounted Cash Flow (DCF) Valuation Engine

### A. Mathematical Specifications
1. **Projected Cash Flows ($FCF_t$):**
   $$FCF_t = FCF_0 \times (1 + g)^t, \quad t \in [1, N]$$
2. **Present Value of Projected Cash Flows ($PV_{\text{proj}}$):**
   $$PV_{\text{proj}} = \sum_{t=1}^N \frac{FCF_t}{(1 + WACC)^t}$$
3. **Gordon Growth Terminal Value ($TV$):**
   $$TV = \frac{FCF_N \times (1 + g_{term})}{WACC - g_{term}}$$
4. **Present Value of Terminal Value ($PV_{\text{TV}}$):**
   $$PV_{\text{TV}} = \frac{TV}{(1 + WACC)^N}$$
5. **Enterprise Value ($EV$):**
   $$EV = PV_{\text{proj}} + PV_{\text{TV}}$$
6. **Enterprise to Equity Value Bridge:**
   $$\text{Equity Value} = EV + \text{Cash} - \text{Total Debt}$$
7. **Intrinsic Value Per Share ($IV$):**
   $$IV = \frac{\text{Equity Value}}{\text{Diluted Shares Outstanding}}$$
8. **Margin of Safety Percentage ($MoS$):**
   $$MoS = \frac{IV - \text{Current Price}}{\text{Current Price}} \times 100$$

## 3. Portfolio Stress Testing Engine

### A. Mathematical Specifications
1. **Universal Signed Position Valuation:**
   $$V_{\text{stressed}} = V \times \max(0, 1 + r)$$
   where $V$ is market value (positive for longs, negative for shorts) and $r$ is asset-specific return shock.
2. **Short Position Symmetry:**
   When $V < 0$ and $r < 0$, price multiplier $m = 1 + r < 1$, resulting in a less negative liability $V_{\text{stressed}} > V$ and a positive dollar gain $\Delta P\&L = V_{\text{stressed}} - V > 0$.
3. **Cash Shock Immunity:**
   Cash holdings carry $\beta = 0$ and $r_{\text{cash}} = 0$, guaranteeing $V_{\text{stressed}} \equiv V_{\text{cash}}$ ($100\%$ capital preservation).
4. **Accounting Conservation Identity:**
   Across all scenarios, the fundamental identity is reconciled to $10^{-4}$ precision:
   $$V_{\text{start}} + \sum_{i} \Delta P\&L_i \equiv V_{\text{stressed}}$$

## 4. Backtesting & Deterministic Replay Engine

### A. Replay Engine Event Ordering & Lookahead Protection

- Strategy `onBar(bar, ctx)` receives a slice of bars restricted to indices $[0 \dots t]$. Access to indices $t + 1$ is impossible.
