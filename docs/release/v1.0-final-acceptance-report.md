## 3. Verified Quantitative Findings

### 3.1 DCF Valuation Model (`lib/fn/dcf.js`, `public/js/fn/dcf.js`)
- **Explicit Forecast & WACC Discounting:** Accurately discounts 5-year free cash flow projections:
  $$EV = \sum_{t=1}^{5} \frac{FCFF_t}{(1 + WACC)^t} + \frac{TV}{(1 + WACC)^5}$$
- **WACC Boundary Enforcement:** Strictly rejects $WACC \le g$ with descriptive mathematical warning, preventing non-converging or negative perpetuity valuations.
- **Enterprise-to-Equity Value Bridge:** Reconciles balance sheet cash and debt:
  $$\text{Equity Value} = EV + \text{Cash} - \text{Total Debt}$$
- **Metamorphic Validation:** Confirmed that higher growth increases EV, higher WACC decreases EV, additional cash adds 1:1 to equity value, additional debt subtracts 1:1 from equity value, and market price movements impact Margin of Safety without altering intrinsic value.

### 3.2 Portfolio Stress Testing (`lib/fn/stress.js`, `public/js/fn/stress.js`)
- **Historical Crisis Engine:** 8 crisis scenarios (2008 GFC -52.6%, 2020 COVID -33.9%, 2022 Rates Shock -24.9%, 2000 Tech Wreck -82.0%, 1987 Black Monday -22.6%, 2011 US Downgrade -17.5%, 2015 China Devaluation -12.4%, 2023 SVB Banking Panic -14.2%) and 4 macroeconomic factor shocks.
- **Factor Accounting:** Fully reconciles initial portfolio value, scenario P&L, and stressed terminal value across long equity, short equity, cash, and commodities.

### 3.3 Historical Backtesting Replay (`lib/replay-engine.js`, `public/js/fn/btst.js`)
- **Execution Semantics:** Next-bar open execution strictly enforced; zero lookahead bias verified by synthetic perturbation harness.
- **Realism Controls:** Gap-through stop losses fill at market open with slippage rather than theoretical stop price.

## 4. Security & Durability Audit

### 4.1 HTTP Perimeter Security
- **Origin & Host Protection:** Non-GET/HEAD mutations require matching Host and `x-qt: 1` header. Opaque/null origins are rejected with `403 Forbidden`.
- **Path Traversal Shield:** Static file serving normalizes paths and enforces base directory boundary confinement.

### 4.2 Windows Filesystem Persistence Hardening
- **Store Hardening:** `lib/store.js` implements collision-proof temporary file naming (`${file}.${pid}.${now}.${rand}.tmp`) and a bounded 5-attempt retry loop to allow transient Windows antivirus or search indexer file locks (`EPERM`, `EBUSY`, `EACCES`) to clear prior to atomic replacement.
