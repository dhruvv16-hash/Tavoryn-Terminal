## 2. Unit Conventions & Dimensional Consistency

### 2.1 Nasdaq Financial Statement Units (`lib/fn/dcf.js`, `lib/fn/des.js`)
- **Source Units:** Nasdaq corporate financial statements report balance sheet and cash flow items in **thousands of USD** (`$000s`).
- **Terminal Model Units:** Tavoryn DCF and valuation models compute in **millions of USD** (`$M`).
- **Conversion Factor:** Source values are divided by 1,000 (`val / 1000`) upon ingestion:
  - Apple Inc. Operating Cash Flow: reported `$118,254,000` (thousands) $\rightarrow \$118,254.0\text{M}$.
  - Apple Inc. Capital Expenditures: reported `$9,451,000` (thousands) $\rightarrow \$9,451.0\text{M}$.
  - Calculated Base FCF: $\$118,254.0\text{M} - \$9,451.0\text{M} = \$108,803.0\text{M}$.
- **Share Count Consistency:** Diluted shares are expressed in millions ($15,555.56\text{M}$ shares for Apple).
- **Per-Share Dimensional Proof:**
  $$\frac{\text{Equity Value (\$M)}}{\text{Diluted Shares (M)}} = \frac{\$1,967,683.09\text{M}}{15,555.56\text{M}} = \$126.49 \text{ per share}$$
  Dimensional units cancel exactly to USD per share.

## 3. Feed Freshness, Staleness & Continuity Rules

1. **Maximum Feed Age:** Quotes older than 15,000 ms trigger a `FEED_STALE` warning in the UI status indicator and reject paper order submission in the Risk Gateway.
2. **Failover Architecture:** Crypto quote resolution queries Binance first; if throttled or disconnected, it seamlessly fails over to Coinbase and Kraken.
3. **Offline / Rate-Limit Resilience:** In offline mode (`QT_OFFLINE=1`), all providers fall back to local JSON fixtures in `test/fixtures/`, ensuring test determinism without network dependency.
